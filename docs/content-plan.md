# Контент-план AppsGames.ru (v1: 50 страниц)

Цель — за 3-4 недели собрать **50 качественных страниц** в 5 тематических кластерах
и сохранить весь ссылочный сок со старого сайта.

## Обозначения

| Поле | Смысл |
|---|---|
| **Status** | `new` — статья с нуля; `migration` — URL новый, но на него уже идёт 301 со старого URL (бэклинки); `keep` — URL остаётся прежним, статья переписывается заново; `hub` — категорийная страница; `infra` — служебная (о проекте, политика, ...) |
| **Priority** | `P0` — делаем в первую очередь (держат бэклинки / критичны для инфраструктуры); `P1` — базовый объём кластеров; `P2` — доборные статьи для связности |
| **Src** | `🔗` — есть внешние ссылки из Ahrefs; `+` — новая статья |

Объём целевой: **1500–2500 слов** на статью-гайд; **2500–3500** на подборку; **800–1200** на hub и инфо-страницу.
