Пакет мобильного интернета в 2026 году — не резиновый. Если под конец месяца упираетесь в лимит, вот список того, что реально помогает.

## iPhone: где смотреть расход

Настройки → **Сотовая связь** → прокрутите вниз.

- Список приложений с затраченным трафиком.
- Переключатели: можно **запретить** приложению использовать сотовую связь.
- **Сбросить статистику** в конце месяца — так увидите реальный расход.

## Android: где смотреть расход

Настройки → **Сеть и интернет** → **Передача данных** (или **Мобильные данные** → **Использование данных**).

- За выбранный период (например, месяц).
- По приложениям.
- Для каждого: можно запретить фоновые мобильные данные.

## 1. Фоновое обновление приложений

### iPhone

Настройки → **Основные** → **Обновление контента** → **Обновление контента** → **Wi-Fi** (или **Выкл.**).

### Android

Настройки → **Сеть → Экономия трафика** → включить.

Режим экономии ограничивает фоновое потребление почти для всех приложений. Исключения (важные) настраиваются отдельно.

## 2. Автозагрузка в мессенджерах

### WhatsApp

Настройки → **Хранилище и данные** → **Автозагрузка медиа**:

- **Через мобильные данные** → снять все галочки.
- **Через Wi-Fi** → оставить фото (видео и аудио — по желанию).

### Telegram

Настройки → **Данные и память** → **Автозагрузка медиа**:

- **Через мобильные** — уменьшите лимиты до «Фото + Голосовые».
- Отключите автозагрузку видео.

### Max / ВКонтакте / Viber

Аналогично — ищите **«Автозагрузка»** или **«Медиа»**.

## 3. Автозагрузка фото в облака

Проверьте, что **НЕ** загружают по мобильной сети:

- **iCloud Photos** (iPhone): Настройки → Фото → Сотовая связь → **Выкл.**
- **Google Photos**: приложение → аватар → Настройки → Резервное копирование → **Только через Wi-Fi**.
- **Яндекс.Диск**: Настройки → Резервные копии → **Только по Wi-Fi**.
- **Dropbox, OneDrive** — аналогично.

Автозагрузка одной свежей фотосессии = 300–500 МБ. Быстро съедает пакет.

## 4. Потоковое видео и музыка

### YouTube

- Приложение → аватар → **Настройки → Параметры видео → Мобильная сеть** → максимум **480p** или **720p**.
- Включите **«Режим экономии данных»**.
- Отключите автовоспроизведение следующего видео.

### Яндекс.Музыка, Spotify, Apple Music

- Качество через мобильную — **Обычное** (не **Высокое**/**Hi-Res**).
- Скачивание — **Только по Wi-Fi**.

Час Spotify на Hi-Res = 150 МБ. На обычном качестве = 40 МБ.

## 5. Соцсети — самый хитрый расход

**Instagram, TikTok** — самые жирные потребители. Видео автовоспроизводится в ленте: прокрутили 10 минут — «съели» 200 МБ.

### Instagram

- Настройки → Использование данных → **Использовать меньше мобильных данных**.

### TikTok

- Профиль → настройки → **Экономия трафика** — включить.

### VK, Facebook

- Найдите **«Автовоспроизведение видео»** и поставьте **«Никогда»** или **«Только по Wi-Fi»**.

## 6. Браузер с экономией

### Chrome

- Chrome → ⋮ → **Настройки → Основные → «Упрощённый режим»** (если есть в вашей версии).
- Это пускает страницы через прокси Google, который сжимает их до 50%.

### Opera / Opera Mini

- Opera Mini штатно экономит трафик через собственные сервера. Не для всех сайтов подходит (платёжки и банки могут не работать), но для соцсетей, новостей — экономия 30–70%.

## 7. Ограничьте обновление приложений

### iPhone

- Настройки → **App Store → Автоматические обновления** → **Сотовые данные — Выкл.**
- Оставьте **Автоматические загрузки** только для покупок, не для обновлений.

### Android (Google Play)

- Play → аватар → Настройки → **Сеть → Автообновление приложений** → **Только через Wi-Fi**.

Одно обновление TikTok = 150 МБ. Пяти приложений в день = почти 1 ГБ в неделю.

## 8. Игры

- Большие игры (Genshin Impact, PUBG Mobile, CoD Mobile) выкачивают обновления по сотни МБ.
- В настройках игры ищите **«Загрузка ресурсов»** — поставьте **«Только Wi-Fi»**.
- Многие игры качают свежий контент даже в фоне — ограничьте фоновые данные для них.

## 9. Видеозвонки

- WhatsApp-, Telegram-, Zoom-звонок в HD ест 500 МБ за полчаса.
- Включайте **SD-качество** или только аудио, когда не критично видеть собеседника.
- В Zoom: Настройки → Встреча → **«Не использовать HD-видео»**.

## 10. Проверяйте расход в середине месяца

Поставьте себе напоминание 15-го числа каждого месяца зайти в **Настройки → Сотовая связь** (iPhone) или **Передача данных** (Android) и посмотреть список. Часто вы обнаружите приложение, которое ест 2 ГБ в месяц «из ниоткуда» — и выключите у него мобильные данные.
