iPhone выдает «не хватает места», в самый неподходящий момент — например, перед съёмкой или обновлением. Разбираем, как быстро освободить 5–30 ГБ без потери важного.

## 1. Где смотреть, что занято

**Настройки → Основные → Хранилище iPhone.**

Подождите 10–20 секунд, пока подгрузится аналитика. Увидите:

- Полосу с цветами: сколько занимают Приложения, Фото, Медиа, Почта, Сообщения, Система, Другое.
- Список приложений, отсортированный по размеру.
- Рекомендации (**«Сгрузить неиспользуемое»**, **«Оптимизировать видео»**).

Начните работу сверху списка — освобождать тяжёлые имеет больший эффект.

## 2. Фотографии и видео

Обычно занимают 30–60% хранилища.

### Оптимизация iCloud

Настройки → Фото → **Оптимизация хранилища iPhone**.

Оригиналы уходят в iCloud, на iPhone остаются сжатые превью — только нужное качество под экран. Когда понадобится полный размер — скачается по запросу.

Минус: нужна подписка iCloud. 200 ГБ — 149 ₽/мес. Для 95% пользователей это окупается одним iPhone.

### Альтернатива — Google Photos

Бесплатно до 15 ГБ (общий с Google Drive), дальше платно. Но это дополнительная копия — удалить из iPhone после загрузки в Google Photos можно вручную, освобождая место.

### Удалить очевидно лишнее

- **Альбом «Скриншоты»** — обычно можно очистить на 90%.
- **Недавно удалённые** — фото там лежат 30 дней, занимают место. Альбомы → Недавно удалённые → Выбрать → Удалить всё.
- **Дубликаты**: Альбомы → Дубликаты → Объединить.
- **Альбомы «Селфи», «Снимки экрана»** — пролистайте и почистите.

## 3. Тяжёлые приложения

В Хранилище iPhone отсортированы по весу. Типичные кандидаты сверху:

- **Safari** — 2–5 ГБ кеша.
- **Telegram** — 5–15 ГБ (кеш каналов).
- **WhatsApp** — 3–10 ГБ (медиа семейных чатов).
- **Spotify / Яндекс Музыка** — 2–5 ГБ (скачанные плейлисты).
- **Игры** (Genshin Impact, PUBG) — 10–20 ГБ.

### Для мессенджеров

- Telegram: Настройки → Данные и память → Использование памяти → Очистить кеш.
- WhatsApp: Настройки → Хранение и данные → Управление хранилищем → Чистить чаты по объёму медиа.

### Для приложений без собственной чистки

- **Сгрузите приложение**: Настройки → Основные → Хранилище iPhone → Приложение → **Сгрузить приложение**. Файл приложения удалится, данные останутся. При следующем открытии скачается заново.
- Или **удалите** и установите заново — обычно размер падает в 2 раза.

## 4. Safari

Настройки → Safari → **Очистить историю и данные сайтов** → **Всё время**.

Освобождает 1–3 ГБ и сбрасывает cookies (вас разлогинит на части сайтов).

## 5. Загрузки Apple Music / YouTube Premium

Забытая музыка и видео на офлайн тоже занимают.

### Apple Music

- Apple Music → Библиотека → Загруженные.
- Тап по исполнителю/альбому → ⋮ → **Убрать загрузку**.

### YouTube Premium

- YouTube → Вкладка **«Вы»** → **Загруженные**.
- ⋮ → **Удалить загрузку**.

### Подкасты

- Подкасты → **Библиотека** → **Загруженные эпизоды**.

## 6. Сообщения

**Настройки → Основные → Хранилище iPhone → Сообщения**.

- **Просмотр крупных вложений** — увидите большие фото и видео из iMessage. Удалите ненужные.
- **Автоматическое удаление сообщений**: Настройки → Сообщения → **Сохранять сообщения** → **1 год** или **30 дней** (если не нужна вся история).

## 7. Почта

- **Настройки → Почта → Учётные записи → [email] → Выгрузить**.
- Помогает, если в почте много вложений.
- Минус: настройки учётной записи сотрутся, придётся заново войти.

## 8. Сгрузить приложения автоматически

Настройки → **App Store** → **Сгружать неиспользуемые** → включить.

iPhone сам будет удалять редко используемые приложения, сохраняя данные. Когда захотите вернуть — тап по иконке (с облачком), приложение скачается.

## 9. Раздел «Другое» / «Системные данные»

Самая загадочная часть: 5–20 ГБ, которые не относятся ни к одной категории. Это временные файлы, журналы, Siri, обновления.

### Что помогает:

- **Перезагрузите iPhone**. Часть временных файлов удалится.
- **Подключите на ночь к зарядке с Wi-Fi** — iOS запускает автоматическую уборку.
- **Обновите iOS** — прошивка часто чистит кеши.
- **Радикально**: сделайте бэкап → Стереть контент и настройки → восстановите из бэкапа. Займёт 2–4 часа, освобождает 10–30 ГБ.

## 10. AirDrop-тайник

Если много раз AirDrop-или файлы — часть может залежаться в **Файлах → На моём iPhone**. Проверьте.

## Чек-лист экспресс-уборки (10 минут)

- [ ] Фото → Альбомы → Недавно удалённые → Очистить.
- [ ] Фото → Альбомы → Дубликаты → Объединить.
- [ ] Telegram → Очистить кеш.
- [ ] WhatsApp → Очистить большие чаты от видео.
- [ ] Safari → Очистить данные сайтов.
- [ ] Настройки → Хранилище → первые 5 приложений из списка проверить, сгрузить редкие.
- [ ] Перезагрузить iPhone.

После этих 7 шагов обычно 5–10 ГБ уже свободно.

  (а лучше 20%) от общего объёма. Под завязку забитый iPhone тормозит —
  системе не хватает места для временных файлов.
