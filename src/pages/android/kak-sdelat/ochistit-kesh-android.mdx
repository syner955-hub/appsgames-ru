На Android очистка кеша делается за 10 секунд, но путь у разных производителей чуть отличается. Разберём универсальный сценарий и частные случаи Samsung, Xiaomi, Huawei.

## Способ 1. Очистка кеша одного приложения

Стандартный путь работает почти на любом Android:

1. **Настройки → Приложения** (или «Приложения и уведомления»).
2. Найдите нужное → тап.
3. **Хранилище и кеш**.
4. **Очистить кеш**.

Всё. Приложение не пострадает, логины сохранятся, но оно «похудеет» на столько, сколько занимал кеш.

### Кеш или данные?

В том же меню есть **«Очистить данные»** — это **стирает приложение в ноль**: логины, настройки, сохранения игр. Фактически то же самое, что удалить и поставить заново.

<Callout type="warn" title="Не путайте">
  «Очистить кеш» — безопасно, теряются только временные файлы.
  «Очистить данные» — небезопасно, стирается всё, включая переписку
  мессенджера, несохранённые в облако данные игр, логины банков.
  Если не уверены — выбирайте только **Очистить кеш**.
</Callout>

## Способ 2. Найти самые «жирные» приложения

Удобно, когда мало места и непонятно, что именно есть:

1. **Настройки → Хранилище** (или «Память»).
2. **Приложения**.
3. Сортировка по размеру — от большего к меньшему.
4. Тап по тяжёлому → **Хранилище и кеш → Очистить кеш**.

Обычно лидеры списка — Telegram, WhatsApp, Instagram, TikTok, Chrome, Яндекс Карты.

## Способ 3. Производительный «Storage Cleaner» Google

На чистом Android (Pixel, Motorola) и на большинстве свежих прошивок есть встроенный ассистент:

1. **Настройки → Хранилище → Освободить место**.
2. Android покажет предложения: файлы из «Корзины» Google Photos, неиспользуемые приложения, большие файлы в Скачанных.
3. Выберите и очистите.

Это безопаснее сторонних «оптимизаторов».

## Способ 4. Samsung, Xiaomi, Huawei — частности

### Samsung (One UI)

- **Настройки → Обслуживание устройства** (Device care) → **Хранилище**.
- Есть разделы «Нежелательные файлы», «Большие файлы», «Дубликаты». Чистите точечно.
- Или через **Настройки → Приложения → [приложение] → Хранилище → Очистить кеш**.

### Xiaomi (HyperOS / MIUI)

- **Настройки → О телефоне → Хранилище → Очистить**.
- Очистка через приложение **«Безопасность»** (предустановлено) → **Очистка**.
- Кеш одного приложения: **Настройки → Приложения → Все приложения → [приложение] → Очистить данные → Очистить кеш**.

### Huawei / Honor

- **Настройки → Память → Очистить память**.
- Или через приложение **«Диспетчер»** → раздел **«Очистка»**.

## Кеш браузера

### Chrome

1. Откройте Chrome → **⋮** справа вверху → **История**.
2. **Очистить данные просмотров**.
3. Период: **Всё время**.
4. Галочки: **Файлы cookie, изображения и другие файлы в кеше**.
5. **Удалить данные**.

### Яндекс.Браузер

- **⋮ → Настройки → Очистить данные** → галочки → **Очистить**.

### Firefox

- **⋮ → Настройки → Удалить данные сёрфинга** → галочки → **Удалить**.

## Кеш системы (через Recovery)

Старый приём, актуальный для подтормаживающих смартфонов после обновления прошивки. На большинстве Android 10+ функция убрана, но на Samsung и Xiaomi ещё доступна:

1. Выключите смартфон.
2. Зажмите **Громкость+ и Питание** (на некоторых — ещё Home) → до появления логотипа.
3. В Recovery найдите **Wipe cache partition**.
4. Подтвердите. Никакие личные данные не удалятся.
5. Reboot system now.

Помогает при подтормаживаниях после обновления Android.

## Что дают «Cleaner»-приложения из Play Store

Ничего хорошего. **Clean Master, SD Maid Pro, AVG Cleaner, CCleaner Android** и десятки аналогов продают подписку за то, что Android делает сам:

- Очистка кеша: Android сам чистит, когда места меньше 5%.
- «Ускорение RAM»: Android автоматически выгружает неиспользуемые приложения по алгоритму LRU. Принудительная выгрузка только замедляет — при возврате приложение загружается заново.
- «Удаление мусора»: часто это не мусор, а нужные файлы (обложки альбомов, кеш карт).

Clean Master в 2018 году был удалён из Play Store за рекламный фрод. Более-менее честных среди них — единицы.

**Единственное полезное из этого класса** — «Files by Google» (бесплатно, от Google). Чистит дубликаты, старые мемы из WhatsApp, неиспользуемые приложения. Без агрессии и подписок.
