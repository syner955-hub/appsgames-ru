Айфон в 2026 всё ещё не любит чужие форматы видео — MKV, AVI, WMV штатное приложение показать не сможет. Но это легко решается плеером и одним из четырёх способов залить файл. Ниже — по порядку.

## Какие форматы iPhone точно покажет

Стандартное приложение «ТВ» (оно же «Фильмы», зависит от региона) играет только **MP4, MOV и M4V** с видеокодеком **H.264** или **HEVC (H.265)** и звуком **AAC** или **Dolby Digital**. Это ограничение iOS, не приложения.

Если у фильма другой контейнер или экзотический аудиокодек (например, DTS), выход один — устанавливать сторонний плеер. Они кодек декодируют программно и играют почти всё.

Оба приложения умеют **принимать файлы напрямую через «Файлы», AirDrop и Wi-Fi-загрузку**. Без них никуда.

## Способ 1. С компьютера через Apple Devices / Finder

Самый надёжный способ для большого видео (2–20 ГБ).

1. Установите на iPhone VLC (или Infuse) из App Store.
2. Подключите iPhone к ПК кабелем.
3. На Windows откройте **Apple Devices**, на Mac — **Finder** → ваш iPhone.
4. Вкладка **Файлы** (раньше называлась «Общие файлы / File Sharing»).
5. Выберите в списке **VLC**.
6. Перетащите фильмы в правую часть окна.
7. Apple Devices / Finder сам синхронизирует файл в приложение VLC. В большинстве случаев это мгновенно — файл просто копируется.

Открываете VLC на iPhone → ваши фильмы уже там.

## Способ 2. Через приложение «Файлы» и облако

Работает без кабеля. Подойдёт, если фильм уже в облаке.

1. Залейте файл в iCloud Drive, Яндекс Диск, Google Drive, Dropbox или OneDrive с любого устройства.
2. На iPhone откройте приложение **Файлы** → перейдите в нужное облако.
3. Нажмите и удерживайте файл → **Поделиться** → **Скопировать в VLC** (или Infuse).
4. Файл скопируется в память плеера и будет играть без интернета.

Если хотите смотреть стримом без скачивания — в VLC есть вкладка **Сеть**: можно подключить WebDAV, SMB или прямой URL и проигрывать файл прямо из облака. Нужно стабильное Wi-Fi, но место в памяти не тратится.

## Способ 3. AirDrop (только с Mac или iPhone/iPad)

Самый быстрый способ для одного файла до пары ГБ, если рядом Mac или другой iPhone.

1. На Mac кликните правой кнопкой по файлу → **Поделиться** → **AirDrop** → выберите свой iPhone.
2. На iPhone появится запрос → **Принять**.
3. iPhone предложит: открыть в «Фото» (если это поддерживаемый формат) или сохранить в «Файлы». Для несовместимых форматов — только «Файлы», оттуда уже откройте в VLC.

## Способ 4. Wi-Fi Upload в VLC

Если нет кабеля и не хочется возиться с облаком.

1. Откройте VLC на iPhone → вкладка **Сеть** → **Обмен через Wi-Fi**.
2. Появится адрес вида `http://192.168.1.45:8080`.
3. На компьютере откройте этот адрес в браузере, когда ПК и iPhone в одной сети.
4. Перетащите файл в открывшуюся страницу.

Скорость — 20–40 МБ/с на нормальном Wi-Fi. Фильм 4 ГБ заливается минут за 2–3.

## Что делать, если видео не открывается

- **Плеер показывает чёрный экран с звуком** — видеокодек не поддержан устройством. Обычно это HEVC на старом iPad (до iPad Air 2). Поможет VLC с программным декодированием.
- **Звук есть, картинки нет** — тот же симптом, лечение тоже.
- **Нет звука, картинка есть** — аудиокодек вроде DTS. В VLC в настройках звука переключите на стандартный канал.
- **Видео подтормаживает** — попробуйте конвертировать в MP4 H.264 заранее (на ПК бесплатный HandBrake).
- **«Файл слишком большой»** — для передачи через AirDrop есть практический лимит ~2 ГБ из-за свободного ОЗУ на iPhone. Используйте кабель.

## Быстрое сравнение способов

| Способ | Нужен кабель | Нужно облако | Скорость | Подходит для |
|---|---|---|---|---|
| Apple Devices / Finder | да | нет | очень высокая | больших файлов 2–20 ГБ |
| Облако + Файлы | нет | да | средняя | если файл уже в облаке |
| AirDrop | нет | нет | высокая | от Mac/iPhone, до 2 ГБ |
| Wi-Fi Upload в VLC | нет | нет | средняя | один файл с ноутбука |
