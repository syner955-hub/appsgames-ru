«Очисти кеш» — первое, что гуглят в ответ на «iPhone тупит». В Android есть эта кнопка в настройках каждого приложения, в iOS — нет. Apple намеренно сделала так, чтобы кеш чистился системой автоматически, когда места становится мало. Но есть места, где можно почистить вручную, и это правда помогает.

## Что такое кеш в iPhone

Кеш — это копии данных, которые приложение сохранило, чтобы ускорить работу. В мессенджере это присланные картинки и видео, в браузере — страницы и изображения сайтов, в соцсетях — аватарки и картинки из ленты. Без кеша приложения работали бы медленнее и ели больше мобильного трафика.

Чистить кеш имеет смысл, когда:

- На iPhone критично мало места.
- Конкретное приложение раздулось до гигабайтов (чаще всего — Telegram, WhatsApp, Яндекс Музыка с офлайн-плейлистами).
- В приложении что-то глючит — перезагрузка кеша часто помогает.

Не имеет смысла делать это «регулярно для профилактики» — iPhone сам справляется.

## Способ 1. Кеш Safari

1. **Настройки → Safari**.
2. Внизу → **Очистить историю и данные сайтов**.
3. Выберите период: **Все время / Последний час / Сегодня**.
4. Подтвердите.

Это удалит историю просмотров, cookies и кеш. Пароли и данные автозаполнения останутся.

<Callout type="warn" title="Что потеряется">
  Вас разлогинит на большинстве сайтов (cookie-сессии пропадут). Для нечастых
  сервисов — не проблема, для банковских и рабочих — зайдите после чистки и
  введите пароль заново.
</Callout>

### Только для одного сайта

Если пролагает только один сайт:

1. **Настройки → Safari → Дополнения → Данные сайтов**.
2. Подождите, пока подгрузится список.
3. Потяните вправо на строке нужного сайта → **Удалить**.

## Способ 2. Кеш мессенджеров

### Telegram

Самое частое место, где копится кеш — Telegram любит копить гигабайты.

1. Telegram → **Настройки** → **Данные и память** → **Использование памяти**.
2. **Очистить кеш Telegram**.
3. Выберите, что удалять: фото, видео, голосовые, файлы, стикеры.
4. Подтвердите.

Там же можно включить **автоматическую очистку** — настроить, что всё старше 3 дней / 1 недели / 1 месяца удалять автоматически.

### WhatsApp

1. WhatsApp → **Настройки** → **Хранилище и данные** → **Управление хранилищем**.
2. Сверху топ по объёму — чаты, где больше всего медиа.
3. Зайти в нужный чат → выделить видео/фото → удалить.

Общую кнопку «очистить кеш» WhatsApp не даёт — работаем с конкретными чатами.

### Max, Viber, Discord, ВКонтакте

В каждом из них настройка лежит в своём месте, но по такому же пути: **Настройки → Хранение данных / Использование памяти → Очистить кеш**.

## Способ 3. Кеш «тяжёлых» приложений без кнопки очистки

Многие приложения (Instagram, TikTok, Netflix, Яндекс Такси) не дают кнопку очистки кеша в своих настройках. Единственный способ стопудово очистить их — **удалить и поставить заново**.

1. Настройки → Основные → Хранилище iPhone.
2. Найдите приложение → тап → **Удалить приложение**.
3. Заново скачайте из App Store.

Минус — придётся снова залогиниться. Плюс — приложение похудеет на несколько сотен МБ.

Альтернатива мягче — **«Сгрузить приложение»** (в том же меню). Сгруженное приложение уходит из памяти, но данные остаются. При повторной установке ничего вводить не надо, но кеш тоже вернётся со временем.

## Способ 4. Очистка «Другое» в Хранилище

В Настройки → Основные → Хранилище iPhone внизу список занятого места. Часто там большой кусок **«Другое»** или **«Системные данные»** — 5–30 ГБ, которые не относятся ни к одному приложению. Это системный кеш: Siri, журналы, обновления, мини-образы установщиков.

Apple не даёт прямой кнопки его чистки. Что помогает:

1. **Перезагрузка** iPhone — часть временных файлов удаляется автоматически.
2. **Обновление iOS** до последней — заодно подчищает кеши старых версий.
3. **Подключение к зарядке на ночь с Wi-Fi** — iOS запускает очистку, если место низкое.
4. **Сделать бэкап → восстановить как новый → восстановить из бэкапа** — радикальный способ, убирает всё ненужное в «Другое». Занимает 2–4 часа, но гарантированно освобождает 10–30 ГБ.

<Callout type="tip">
  Не ставьте приложения из App Store с названиями «Cleaner», «Cache Cleaner»,
  «iPhone Booster». В iOS невозможно из стороннего приложения почистить кеш
  системы или других приложений — API это запрещает. Такие приложения —
  пустышки с рекламой и платными подписками.
</Callout>

## Сколько реально можно освободить

Реалистичные цифры на забитом iPhone:

- Safari: 0.5–2 ГБ.
- Telegram: 2–15 ГБ (у активных пользователей каналов с видео).
- WhatsApp: 1–10 ГБ (у тех, кто в семейных чатах с видео).
- Instagram / TikTok (удаление и переустановка): 1–3 ГБ.
- Системное «Другое»: 5–15 ГБ после восстановления «как новый».

Итого на почти полном iPhone после полной чистки освобождается 10–30 ГБ без удаления ничего важного.
