## Описание Signal

Signal разработан некоммерческой организацией Signal Foundation. Мессенджер полностью финансируется за счёт пожертвований и не монетизирует данные пользователей. Исходный код приложения открыт и регулярно проходит независимый аудит безопасности. Signal поддерживает все стандартные функции общения при максимальном уровне конфиденциальности.

Ключевые особенности:

- Сквозное шифрование по протоколу Signal Protocol
- Открытый исходный код с регулярным аудитом
- Отсутствие рекламы и трекеров
- Исчезающие сообщения с гибкой настройкой таймера
- Защита экрана от скриншотов
- Анонимный отправитель для скрытия метаданных

## Основные функции

- **Защищённые чаты** — все сообщения шифруются на устройстве отправителя и расшифровываются только у получателя
- **Голосовые и видеозвонки** — зашифрованные вызовы с поддержкой групповых звонков до 40 человек
- **Заметки для себя** — личное пространство для сохранения текстов, ссылок и файлов
- **Размытие лиц** — встроенный инструмент для анонимизации фотографий перед отправкой
- **Блокировка приложения** — дополнительный PIN или биометрия для входа в мессенджер
- **Прокси-поддержка** — возможность обхода блокировок через прокси-серверы
