Chrome для Android построен на движке Blink и оптимизирован для работы на мобильных процессорах. Браузер синхронизирует закладки, пароли, историю и открытые вкладки между всеми устройствами через аккаунт Google. Встроенный менеджер паролей генерирует и хранит учётные данные. Режим экономии трафика сжимает страницы через серверы Google.

Ключевые особенности:

- Синхронизация данных между всеми устройствами через Google-аккаунт
- Встроенный переводчик страниц на 100+ языков

## Как скачать Google Chrome на Android

1. Откройте Google Play: [https://play.google.com/store/apps/details?id=com.android.chrome](https://play.google.com/store/apps/details?id=com.android.chrome)

## Основные функции

- **Синхронизация вкладок** — доступ к открытым страницам с любого устройства, привязанного к аккаунту
- **Встроенный переводчик** — автоматический перевод веб-страниц без установки расширений
- **Safe Browsing** — предупреждения при переходе на опасные и мошеннические сайты
- **Группы вкладок** — объединение связанных страниц в именованные группы для удобной навигации
- **Офлайн-страницы** — сохранение статей для чтения без подключения к интернету
- **Голосовой поиск** — ввод запросов голосом через интеграцию с Google Assistant
